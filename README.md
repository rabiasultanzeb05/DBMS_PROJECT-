## Project Title : Delivery Performance Optimization System Using Data Analytics

## Project Description:

The Delivery Performance Optimization System is a database-driven analytics project designed to improve the efficiency of logistics and delivery operations. It uses MySQL for data storage and Streamlit for visualization to analyze deliveries, drivers, and delivery zones.

The system helps identify delivery delays, monitor driver performance, analyze zone congestion, and detect risky deliveries using SQL queries, views, and analytical functions. It converts raw operational data into meaningful insights to support better decision-making and improved customer satisfaction.

---

## Objective:

To build a database-based system that analyzes delivery operations and improves logistics efficiency using SQL and data analytics techniques.

---

## Features:

- Manage orders, deliveries, drivers, and zones  
- Track delivery performance and delays  
- Analyze driver efficiency  
- Identify high-risk deliveries  
- Zone-wise congestion analysis  
- Peak order time analysis  
- Interactive dashboard using Streamlit  

---

## Tech Stack:

- Python  
- Streamlit  
- MySQL  
- Pandas
